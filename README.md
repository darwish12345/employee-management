# 👥 Employee Management System - HR Dashboard

A comprehensive employee management system for HR departments to manage employee records, track departments, and visualize workforce analytics.

## 📖 About The Project

Employee Management System is a web-based HR dashboard that allows administrators to manage employee information, track departmental distribution, and monitor key workforce metrics. Perfect for small to medium businesses.

## ✨ Features

- 📊 **Dashboard Analytics** - View total employees, active staff, department count, and average salary
- 👤 **Employee Management** - Add, edit, view, and delete employee records
- 🏢 **Department View** - Browse employees by department with visual cards
- 📈 **Department Chart** - Visualize employee distribution across departments
- 🔍 **Search & Filter** - Find employees by name, email, or position
- 🏷️ **Status Tracking** - Track employee status (Active, Inactive, On Leave)
- 💾 **Data Persistence** - All data saves automatically in browser
- 📤 **Export Data** - Download employee database as JSON
- 📥 **Import Data** - Upload previously exported employee data
- 📋 **Sample Data** - Load demo employees to test functionality
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile

## 🚀 How To Use

### 1. Run the Application
- Open `index.html` in your web browser
- Or use Live Server in VS Code

### 2. Manage Employees
- **Add Employee** - Click "Add Employee" → Fill form → Submit
- **Edit Employee** - Click edit icon → Modify details → Save
- **Delete Employee** - Click delete icon → Confirm deletion

### 3. View Data
- **Dashboard** - View key metrics and department chart
- **Employees List** - Browse all employees in table format
- **Departments** - Click department cards to filter employees
- **Settings** - Export, import, or load sample data

### 4. Search & Filter
- **Search** - Type in search box to find employees by name
- **Filter** - Use dropdown to filter by department
